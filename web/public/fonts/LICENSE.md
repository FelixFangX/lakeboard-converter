# Fonts

Both fonts are subsets (Basic Latin plus a few symbols), self-hosted so the site makes no third-party requests.

- `instrument-serif-400.woff2`: Instrument Serif Regular. Copyright 2022 The Instrument Serif Project Authors (https://github.com/Instrument/instrument-serif).
- `jetbrains-mono-400.woff2`: JetBrains Mono Regular, without ligatures. Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
